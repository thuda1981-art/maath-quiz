# تحدي الرياضيات — نسخة بيتا

منصة لحل مسائل رياضيات الصف الثاني المتوسط (الفصل الدراسي الأول): فصل الأعداد النسبية، وفصل الأعداد الحقيقية ونظرية فيثاغورس — 14 درساً و 112 سؤالاً.

## المميزات
- **التسجيل بالاسم والصف** ومنع إنشاء حساب جديد من نفس عنوان IP (مع إمكانية استعادة الحساب بنفس الاسم).
- **الفصول كمربعات**، وعند الضغط على الفصل تظهر دروسه.
- **نظام مستويات**: الدرس الأول مفتوح، وكل درس يُفتح بعد إنهاء الدرس الذي قبله بالكامل. الفصل الثاني يُفتح بعد إنهاء الفصل الأول.
- **شرح تفاعلي لكل درس**: فكرة الدرس، القواعد، وأمثلة محلولة تظهر خطوة بخطوة.
- **3 قلوب لكل درس**: عند الخطأ الثالث يعود الطالب للشرح، ثم يكمل الأسئلة من حيث توقف.
- السؤال الخاطئ لا تُكشف إجابته، ويعود في آخر الدرس، ولا يكتمل الدرس إلا بحل كل أسئلته.
- الأسئلة في كل درس من السهل إلى المتوسط إلى الصعب.
- **الصدارة**: النقاط تُحسب فقط على الإجابة الصحيحة من أول محاولة (سهل 10، متوسط 20، صعب 30).
- **لوحة المعلم** على `/admin`: الطلاب وتقدمهم، حذف أو تصفير طالب، تصدير Excel، إعادة تحميل المنهج.

## التشغيل على جهازك
يحتاج **Node.js 22.13 أو أحدث** فقط (لا توجد مكتبات تحتاج تثبيت).
```bash
TRUST_PROXY=0 npm start
```
ثم افتح: http://localhost:3000 — ولوحة المعلم: http://localhost:3000/admin (كلمة المرور الافتراضية `admin123`).

## النشر على الإنترنت (مجاني) — Render + Neon
البيانات تُحفظ في قاعدة بيانات PostgreSQL دائمة على Neon، فلا تضيع عند إعادة تشغيل الموقع.

1. **ارفع المشروع على GitHub** (مستودع جديد، ارفع كل الملفات ما عدا مجلد `data`).
2. **أنشئ قاعدة البيانات**: سجّل في https://neon.tech ← New Project ← انسخ **Connection string** (يبدأ بـ `postgresql://`).
3. **أنشئ الموقع**: سجّل في https://render.com ← New ← Web Service ← اختر المستودع، ثم:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance type: Free
4. **متغيرات البيئة** (Environment):

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | رابط Neon الذي نسخته |
   | `ADMIN_PASSWORD` | كلمة مرور قوية للمعلم |
   | `NODE_VERSION` | `22.13.0` |
   | `MAX_PER_IP` | `1` (انظر الملاحظة المهمة أدناه) |
   | `TRUST_PROXY` | `1` |

5. اضغط Deploy — ستحصل على رابط مثل `https://math-quiz.onrender.com` شاركه مع الطلاب.

> الخطة المجانية في Render "تنام" بعد 15 دقيقة بدون زوار، وأول فتح بعدها يأخذ ~50 ثانية. للاستخدام الفعلي مع الطلاب يُفضّل الخطة المدفوعة ($7 شهرياً) أو Railway.

## ⚠️ ملاحظة مهمة عن قفل الـ IP
كل الأجهزة المتصلة **بنفس شبكة الواي فاي** (مثل شبكة المدرسة أو البيت) تظهر للموقع بـ **نفس عنوان IP**.
- إذا كان الطلاب سيحلّون من بيوتهم: اترك `MAX_PER_IP=1`.
- إذا كانوا سيحلّون من معمل المدرسة على شبكة واحدة: ارفع القيمة (مثلاً `MAX_PER_IP=40`) وإلا فلن يستطيع التسجيل إلا طالب واحد.
- إخوة في نفس البيت سيواجهون نفس المشكلة — يمكن للمعلم رفع الحد أو حذف حساب من لوحة المعلم.

## تعديل الدروس والأسئلة
المنهج كله في `tools/build_curriculum.py` (سهل القراءة والتعديل)، ومنه يُبنى ملف `curriculum.json` الذي يقرأه الموقع:
```bash
python3 tools/build_curriculum.py
```
- كل سؤال يُكتب هكذا، والإجابة الصحيحة تُكتب كنص (الموقع يخلط ترتيب الاختيارات تلقائياً):
  `q(المستوى 1/2/3, "نص السؤال", ["اختيار", "اختيار", ...], "الإجابة الصحيحة", "الشرح")`
- الرياضيات بين علامتي `$`: الكسر `$3/4$`، العدد الكسري `$2 1/3$`، الأس `$5^2$`، الكسر الدوري `$0.{3}$`.
- لا تغيّر ترتيب الأسئلة الموجودة بعد بدء الطلاب (رقم السؤال مرتبط بترتيبه في الدرس). الإضافة في آخر الدرس آمنة.
- بعد التعديل: ارفع الملفات لـ GitHub، أو اضغط "إعادة تحميل المنهج" في لوحة المعلم.

## هيكل الملفات
```
server.js        الخادم وكل الواجهات البرمجية
db.js            قاعدة البيانات (PostgreSQL عند وجود DATABASE_URL، وإلا SQLite محلياً في data/)
curriculum.json  المنهج: الفصول ← الدروس ← الشرح والأسئلة
tools/           أداة بناء المنهج
public/          صفحات الموقع (index.html, admin.html, app.js, style.css)
```
